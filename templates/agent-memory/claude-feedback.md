# Agent feedback log

The user or agent can add one line whenever the workflow helps or gets in the way. No polishing
needed. Record the concrete behavior, not private message contents or credentials.

Format: `YYYY-MM-DD | author | helpful / friction | what happened | change and validation, if resolved`.
At weekly review, choose 1–3 items and improve the environment: instructions, tools, handoff or
work allocation. Stay within existing authorization. Record what changed beside the item and
check the effect next week. Do not turn this into a second application tracker.
